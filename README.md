# ZCORP AI 👑 ZEUS — Worldclass Frontend v7

Upload these flat files to the root of the GitHub Pages repository:
- index.html
- style.css
- main.js

This build includes localStorage login/accounts, chat history, memory, files, premium code redemption, bank/Opay upgrade flow, responsive mobile UI, and a secure Render backend connection.

The default backend URL is `https://zcorp-bot.onrender.com` and can be changed in Settings.

For live Gemini responses, deploy the matching ZEUS backend as a Render Web Service and add `GEMINI_API_KEY` to the backend environment. Do not expose the API key in GitHub Pages.
